{%- comment -%} Emits the site's own content as a graph: articles, projects and the topics that connect them. Tags come from posts, stack entries from projects; both are topics, which is what makes the graph connected rather than a set of stars. {%- endcomment -%} {%- assign topic_names = "" -%} {%- for post in site.posts -%}{%- for tag in post.tags -%}{%- assign topic_names = topic_names | append: tag | append: "||" -%}{%- endfor -%}{%- endfor -%} {%- for project in site.projects -%}{%- for tool in project.stack -%}{%- assign topic_names = topic_names | append: tool | append: "||" -%}{%- endfor -%}{%- endfor -%} {%- assign topics = topic_names | split: "||" | uniq | sort -%}
